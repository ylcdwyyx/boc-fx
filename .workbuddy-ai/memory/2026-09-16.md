# 2026-09-16

## 中行美元牌价手机小组件数据源（替代已停服的「跨境go」）

**背景**：用户原用「跨境go」App 的桌面组件查看中国银行美元现钞买入价，该 App 已停止服务。

**方案**：自建数据源 + 手机端 KWGT 桌面小组件。数据抓取交给 GitHub 云端，手机只负责读取显示。

**产出文件**
- `boc_rate.py` — 抓取 `https://www.boc.cn/sourcedb/whpj/`，零第三方依赖（仅标准库）
- `index.html` — 网页版查看页，手机可「添加到主屏幕」当快捷入口
- `.github/workflows/update.yml` — GitHub Actions 每 30 分钟自动抓取并提交
- `手机端配置指南.md` — KWGT 操作步骤
- `README.md`

**关键坑（重要）**
- 中行牌价页面**响应头不带 charset**，但页面 meta 声明 `charset=utf-8`。
  若按常见经验默认用 GBK 解码，中文全部乱码，导致币种名匹配失败（报"未匹配到币种"）。
  正确做法：解析前 2KB 的 meta charset，取不到再依次尝试 utf-8 / gbk。
- 该页面币种顺序按拼音排列，**美元不在第一行**（在"新台币"之后）。
- 部分币种（新台币、文莱元、印度卢比、巴西雷亚尔、林吉特等）没有现汇价，只有 3 个价格，
  需按价格个数分支处理，否则会列错位。
- 美元行的"发布日期"列实际是 datetime（`2026/09/16 19:13:33`），"发布时间"列才是纯时间。

**部署信息**
- 仓库：https://github.com/ylcdwyyx/boc-fx （公开）
- 数据地址：https://ylcdwyyx.github.io/boc-fx/rate.json
- 网页地址：https://ylcdwyyx.github.io/boc-fx/
- Pages：main 分支 / 根目录，legacy 构建
- Actions 版本：checkout@v7 + setup-python@v7（v4/v5 会触发 Node.js 20 弃用警告）

**验证结果**
- Actions 首次运行成功（GitHub 服务器可正常访问 boc.cn）
- Pages 两个地址均 HTTP 200
- 数据准确：美元现钞买入价 669.55 / 现钞卖出价 672.36
